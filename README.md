## Как запускать Java-практики
Проекты можно открыть в IntelliJ IDEA. Команды запуска указаны в README каждой работы. Для ПР №9 и №10 нужен JDK 17 или новее. В Windows скрипт `run_selfcheck.bat` запускает проверки, а с аргументом `--interactive` открывает ввод с клавиатуры.
