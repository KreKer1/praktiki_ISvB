# Практическая работа №9

Коллекции Java и складской учёт оборудования. Вариант 18.

## Запуск

Нужен JDK 17 или новее. Открой папку pr9 в терминале.

| Режим | Windows | Linux или macOS |
|---|---|---|
| Проверки кода и CSV | ` .\run_selfcheck.bat ` | `bash run_selfcheck.sh` |
| Ввод команд | ` .\run_selfcheck.bat --interactive ` | `bash run_selfcheck.sh --interactive` |

В IntelliJ запускай `ru.edu.pr06.SelfCheck`. Рабочая папка — `pr9` или корень `repo_push`. Для ввода команд добавь `--interactive` в Program arguments.

## Где что лежит

- `StockItem.java` — карточка, остаток, проверка данных и сравнение по коду.
- `Warehouse.java` — каталог, приход, выдача, поиск, сводка, фильтр истории.
- `SelfCheck.java` — 18 базовых проверок, 4 проверки варианта, CSV и консоль.
- `data/sample.csv` — карточки и ожидаемые результаты. У четырёх строк варианта добавлены поля `ISSUE` и дата в формате ГГГГ-ММ-ДД. Выдача берёт количество из четвёртого поля.
- [Диаграммы](diagrams), [решения](DECISIONS.md), [отчёт](Отчёт_ПР9.docx).

## Что показать на защите

Открой `Warehouse.issue`. В будний день склад проверяет карточку и остаток, после удачной выдачи пишет движение. В выходной до списания дело не доходит. В `addMovementsByType` покажи цикл, который собирает записи одного типа.

Ввод с клавиатуры:

```text
add NB-01 Notebook COMPUTER 12
receive NB-01 5
issue NB-01 4
find COMPUTER
totals
exit
```

В режиме ввода `issue` берёт текущую дату компьютера, а название в `add` вводится одним словом. Для показа выдачи в любой день используй проверки с заданными датами в SelfCheck.
